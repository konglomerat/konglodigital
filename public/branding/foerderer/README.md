| -------------------------------- | ------------------------------------- |
| `anstiftung.png`                 | Stiftungsgemeinschaft anstiftung & ertomis |
| `verbund-offener-werkstaetten.png` | Verbund Offener Werkstätten         |
| `kulturbuero-dresden.png`        | Kulturbüro Dresden                    |
| `netzwerk-immovielien.png`       | Netzwerk Immovielien                  |
| `ifm.png`                        | IfM — Initiativen für Materialkreisläufe |
| `nytt-materialdepot.png`         | nytt.Materialdepot                    |

Fehlt eine Datei, zeigt die Kachel den Namen als Alt-Text — die Seite bleibt
lesbar, sieht aber unfertig aus.
