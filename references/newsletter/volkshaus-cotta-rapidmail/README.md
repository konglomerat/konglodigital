# Rapidmail-Referenz: Neues aus dem Volkshaus Cotta

Gesicherte Benutzer-Vorlage aus dem Rapidmail-Konto von Konglomerat e.V.

- Vorlagenname: `Neues aus dem Volkshaus Cotta`
- Rapidmail-Vorlagen-ID: `341386`
- Abrufdatum: 2026-09-01
- Umfang: vollständiges responsives E-Mail-HTML und 12 Bilddateien

## Dateien

- `rapidmail-template.original.html`: unveränderte, vom Browser geladene Vorlage mit den ursprünglichen Rapidmail-Bildadressen
- `index.html`: lokale Referenzkopie; die Bildadressen wurden auf `images/` umgestellt
- `images/`: alle in der Vorlage verwendeten Fotos, Illustrationen und Social-Media-Icons
- `styles/fonts.css`: von der Vorlage eingebundene Schriftdefinitionen
- `assets.json`: Zuordnung der ursprünglichen Rapidmail-Adressen zu den lokalen Dateien

Die Vorlage enthält historische Beispielinhalte. Für das Newsletter-Tool sollten daraus vor allem Layout, Farben, Typografie, Hausillustration, Personenmuster und Footer-Struktur übernommen werden; Projekttexte und Kampagnenbilder bleiben dynamische Newsletter-Inhalte.
